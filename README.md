# 🐯 Tiger Devs - Jogo de Slots (Caça-Níqueis)

Um jogo interativo de caça-níqueis (slots) com tema personalizado, desenvolvido com foco em estilização moderna, separação de conceitos de design (CSS externo) e práticas recomendadas de acessibilidade.

## 🚀 Funcionalidades

- **Sistema de Apostas Dinâmico:** Gerenciamento de saldo fictício e valor da aposta por rodada.
- **Modo Turbo:** Alternância de velocidade para jogadas mais rápidas.
- **Interface Responsiva:** Alinhamento simétrico e limpo dos botões de ação e do painel de saldo.
- **Grade Interativa:** Sistema de slots simulando uma matriz 3x3 de símbolos.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessível da interface.
- **CSS3:** Estilização baseada em Flexbox, design limpo sem o uso de estilos em linha (*inline styles*).
- **JavaScript (Vanilla):** Lógica do jogo, manipulação do DOM e controle de saldo/apostas.

## 📐 Boas Práticas Aplicadas

Durante o desenvolvimento deste projeto, foram aplicadas as diretrizes modernas de desenvolvimento web:
- **Refatoração de CSS:** Todo o estilo em linha (`style="..."`) foi migrado para um arquivo externo (`style.css`), melhorando a manutenção do código.
- **Acessibilidade:** Botões devidamente identificados com o atributo `type="button"` e rótulos de texto legíveis.
- **Estruturação Semântica:** Uso correto de tags e containers baseados em classes reutilizáveis (como `.button-container`).

## 💻 Como Rodar o Projeto

   ```bash
   git clone https://github.com
   ```
2. Abra o arquivo `index.html` no seu navegador ou utilize a extensão **Live Server** no VS Code.
